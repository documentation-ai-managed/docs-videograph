## Overview

VideoGraph empowers you to create, organize, and manage comprehensive documentation for your projects effortlessly. Build structured knowledge bases with an intuitive interface, collaborative editing, and powerful search capabilities. Whether you document APIs, user guides, or internal wikis, VideoGraph scales with your needs.

## Quick Start

Get up and running in minutes with these essential steps.

<Steps>
  <Step title="Sign Up" icon="user-plus">
    Create your free account at `https://app.videograph.com/signup`.

    <Callout kind="tip">
      Use your work email for team invites.
    </Callout>
  </Step>
  <Step title="Create Workspace" icon="folder-plus">
    Set up a new workspace for your project.

````tsx
// Example: Initialize workspace via API (optional)
const workspace = await fetch('https://api.videograph.com/workspaces', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${YOUR_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ name: 'My Project Docs' }),
});
````
  </Step>
  <Step title="Add First Page" icon="plus">
    Click "New Page" and start writing with Markdown or our visual editor.
  </Step>
  <Step title="Publish" icon="globe">
    Preview, then publish your site live.
  </Step>
</Steps>

<CodeGroup tabs="CLI,API">
````bash
# Install VideoGraph CLI
npm install -g @videograph/cli

# Create new docs site
videograph init my-docs-site
cd my-docs-site
videograph dev
````

````javascript
// API setup example
import { VideoGraph } from '@videograph/sdk';

const client = new VideoGraph({ apiKey: 'YOUR_API_KEY' });
await client.pages.create({
  title: 'Welcome',
  content: '# Hello VideoGraph\nStart documenting here.',
});
````
</CodeGroup>
