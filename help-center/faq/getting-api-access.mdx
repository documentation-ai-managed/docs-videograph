## Overview

To use VideoGraph's API, you need an API key.

## Steps

1. Sign in at `https://dashboard.videograph.com`
2. Go to the "API Keys" section
3. Click "Generate New Key"
4. Copy your key (save it securely)

## Usage

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://api.videograph.com/v1/projects
```
